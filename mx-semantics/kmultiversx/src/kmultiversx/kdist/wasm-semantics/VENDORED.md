# Vendored: K semantics of WebAssembly

Unmodified copy of `pykwasm/src/pykwasm/kdist/wasm-semantics/` from
[runtimeverification/wasm-semantics](https://github.com/runtimeverification/wasm-semantics),
at the release recorded in `deps/kwasm_release` at the repository root.
See `LICENSE` in this directory.

Do not edit these files in place. To move to another release, run
`scripts/update-wasm-semantics.sh <version>` and commit the result. Lemmas
about the functions defined here belong with the other lemmas of this
repository, not in this directory.

The Python package `pykwasm` of the same release is still installed, for its
Wasm binary parser. Its copy of these files is no longer used.
